One ZIP contains all payloads. No external payload companions. Select this ZIP from external USB-OTG storage in the exact supplied OrangeFox R12.0_202610011528 crypto recovery. Slot B logical contents in super are empty, so B is not an old-ROM rollback. Installation is not atomic. The ZIP does not format userdata/metadata, erase keys, modify encryption/verity flags, unlock/relock, change slots, or reboot.

Clean installation is the only intended test workflow; existing data migration is unvalidated. Clean-data initialization with encryption retained and future recovery access require separately verified procedures. The ZIP does not provide or certify those procedures. If a write fails, do not boot system or assume slot B can roll back. Save recovery logs and use a separately established restoration procedure. Successful offline validation does not establish safe device boot or power-loss recovery.
